# Windy City Property Services website

The website for Windy City Property Services: contract janitorial, office, and multi-family residential cleaning across Chicagoland.

## Files

| Path | What it is |
|---|---|
| `index.html` | The whole site (one page with sections) |
| `assets/css/style.css` | Colors, fonts, layout |
| `assets/js/main.js` | Menu, service panels, quote drawer, form sending |
| `assets/img/logo-mark.svg` | Logo symbol (skyline in an arch) |
| `assets/img/logo-lockup-*.png` | Full logo in beige, black, and on forest green |
| `assets/img/favicon.svg` | Browser tab icon |

## Things to finish before launch

1. **Connect the forms.** Open `assets/js/main.js` and paste your form service URLs into `FORM_ENDPOINTS` at the top. The careers form uploads resumes, so it needs a service whose plan accepts file uploads.
2. **Business email.** The site shows `info@windycityps.com`. If you choose a different address, search the files for it and replace every copy.
3. **Custom domain.** After buying the domain, add it under Settings > Pages > Custom domain, then point the domain's DNS at GitHub Pages.
